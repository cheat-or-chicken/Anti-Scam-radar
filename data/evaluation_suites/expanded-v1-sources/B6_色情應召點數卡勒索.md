# B2-2 點數卡驗證身分？ 線上尋芳遭勒索

- 來源：165 打詐儀錶板　類型：色情應召詐財 → 性影像勒索
- 用途：**B 堆 — 重建成對話當測試集 ＋ 餵詐騙 agent（共用）**
- 註：此則含二次收割（第 6 幕）的完整樣態，對訓練 agent 的「拖延與加碼」很有用

## 原始敘事

我在Facebook滑到一則極具暗示的貼文，隨即在貼文下方留言表示有興趣，對方主動加我為好友，先透過Messenger聊天，我將自己的LINE給對方，清楚對方在網路貼那些露骨照片的用意，雙方心照不宣，想說約出來見面進一步交流。怎料，對方卻表示，公司有規定，必須先購買指定的點數才能安排見面，透過點數卡驗證身分才能順利約會。

順著對方的各種要求，我買了一堆點數卡，將序號全數拍給對方查看，人還沒約出來，對方又主動提議視訊裸聊，我想要的是一親芳澤，不是對著冷冰冰的畫面隔靴搔癢，拒絕了視訊，對方卻因此將我封鎖。

事後，我透過Messenger詢問封鎖原因，雙方把問題說開，這才解除封鎖，對方又要求進行視訊，這次，我答應了。

結果，視訊結束沒多久，對方馬上翻臉不認人，語氣不善地要求我繼續購買更多點數卡，並傳來一張視訊畫面截圖，以此威脅，若我不從，就要把這些影像散布給我的親友圈。

## 官方話術解析（165 原文）

1. 詐騙集團透過社群平台刊登徵友貼文，謊稱見面需要完成會員資格、身分驗證或其他程序，要求購買點數卡。
2. 利用感情關係說服被害人進行私密視訊，再暗中截圖或錄影。
3. 取得影像後，以公開影像、傳給親友等方式恐嚇，要求持續付款或購買點數。

## 對詐騙 agent 特別有價值的一點

**「封鎖 → 被害人主動回來求和 → 解除封鎖」** 是一個高階操控手法：
用撤回關注來製造稀缺感，讓被害人反過來投入更多。
詐騙 agent 應學會這一招（當對方猶豫時，適度撤退而非加壓）。
