# B1-1 免費拍立得贈送？ 小心踏入詐團陷阱

- 來源：165 打詐儀錶板　類型：假贈品 → 假物流 → 假客服（利益路線）
- 用途：**B 堆 — 重建成對話當測試集 ＋ 餵詐騙 agent（共用）**
- 角色接力：賣家 → 假客服 → 假銀行專員

## 原始敘事

某天Threads上滑到一則「贈送拍立得」的貼文，內容提及某相館即將歇業，店內庫存的拍立得因此拿出來送給有緣人，我主動聯繫對方，並加入對方提供的LINE。對方表示拍立得免費，但運費自付，接著傳來一個賣貨便連結給我，叫我直接點進去填寫資料。

我照著網站上的指示操作，到畫面突然跳出「交易訂單失敗，需實名認證」的警示訊息。我詢問對方怎回事？對方說，要趕緊聯繫客服處理，否則帳號就被凍結了！

我當下也緊張起來，連忙依照頁面的聯繫方式加入客服LINE，客服開始教導我如何正確操作，並且又轉介紹一名銀行專員的LINE，協助解除帳號異常與實名認證的程序。

兩方人馬輪番上陣，說得煞有其事，我逐漸沒了戒心。系統驗證要求網路轉帳？照辦！操作無卡提款、掃描QR-Code付款？馬上處理！

老實說，過程中我其實覺得有點奇怪，我才在賣貨便頁面輸入資料而已，怎麼後續會需要做這麼多金融操作？不過，客服與銀行專員均表示，若沒有完成驗證程序，不只我帳戶被鎖，連賣家帳號也會受我牽連影響，希望我趕緊解決問題，之前操作的款項也都會如數退回。

後來，對方進一步要求我用信用卡購買數位禮券及遊戲點數卡來測試帳戶是否解鎖，並且把序號提供給他們查驗真偽。好不容易才盼到他們告訴我完成驗證，接下來就是退款了。

折騰老半天，我以為終於可以拿到拍立得，沒想到對方又說退款還要跑流程，要我耐心等待。我心中警鈴才開始響起，越想越不對勁，多次透過LINE追問卻始終沒人回應。

## 官方話術解析（165 原文）

1. 假冒店家名義佯稱無償贈送拍立得，吸引民眾上鉤主動聯繫，再提供仿冒的物流交易頁面。
2. 以「交易失敗」、「帳號遭凍結」、「需要實名認證」等訊息，順勢安排假客服及假專員登場，進行各種金流驗證的網銀操作。
3. 待被害人操作完成後，假意承諾全數退款，藉此拖延時間，最後直接失聯。

## 重建後要標的危險動作

點擊連結 / 網路轉帳 / 無卡提款 / 掃描QR-Code付款 / 購買點數卡並提供序號
→ **第一個危險動作 = 點擊賣貨便連結**（但真正的控制權喪失點 = 第一次網路轉帳，兩個都標）
