# B1-3 網友想見的不是你 是你荷包的錢

- 來源：165 打詐儀錶板　類型：假交友 → 見面費（親密路線，慢節奏）
- 用途：**B 堆 — 重建成對話當測試集 ＋ 餵詐騙 agent（共用）**
- 角色接力：網友 → 「經理」
- **這則對話最長、節奏最慢，是測「提前示警」數字最漂亮的一則**

## 原始敘事

我在抖音滑短影音時，認識一位網友，聊沒多久，對方便提議改到通訊軟體LINE聊天，表示LINE比較方便聯絡。網友自稱是一名酒吧調酒師，平時工作忙碌，客人來來去去，沒一個人值得他深交，直到在網路遇到了我。

我被對方的油腔滑調撩得心花怒放，常關心彼此的生活，也分享工作上的趣事。每天幾乎都要上線聊天，讓我漸漸芳心暗許，期待有一天從虛擬情人走向真實關係。一段時間後，對方主動約我一起喝下午茶，讓我既期待又緊張，到了約定當天，還特地打扮了一下並提早出門，希望能留下好印象。

依約抵達見面地點後，卻遲遲盼無對方出現。我傳訊息詢問，他才回覆說公司臨時有點狀況，要我先加入他們經理的LINE，聲稱他違反公司員工不能私下和陌生網友見面的規定，必須由經理確認我的身分後，才能出門赴約。

愧疚又心急的我，馬上加入對方經理LINE。經理告訴我，為了避免員工私下接觸警方臥底或有糾紛的人，必須先確認我的身分，需要我操作ATM提領現金，並將交易明細拍給他看，明細上面會有「職業代碼」，藉此來確認我不是警察。

如約照做後，經理又說，第一次與公司員工約出來見面，需要先以點數卡支付見面保證費，甚至還要求我分別到不同的超商購買，以免一次買太多點數卡引發店員起疑，到時候見面之約就泡湯了。

當我將第一家的點數卡序號傳送出去後，對方不斷催促我繼續購買點數與拍照傳送。我這時越想越不對勁，買點數卡才能見網友的劇情套路，似乎好像跟警方宣導內容一樣，仔細查證後，真的被騙了。

## 官方話術解析（165 原文）

1. 詐騙集團先透過抖音等社群平台搭訕，再引導至LINE聊天，培養感情與信任。
2. 當被害人投入感情後，主動提出見面邀約，再謊稱員工不能私下與陌生人見面，必須經由經理審核。
3. 要求提款、匯款再拍攝交易明細，佯稱以職業代號確認非警職身分。
4. 要求購買高額遊戲點數作為保證金、見面費或驗證費，取得點數序號後便持續要求追加。

## 重建後要標的危險動作

ATM提領並拍交易明細 / 購買點數卡 / 提供點數卡序號

## 註記

「**分不同超商買、以免店員起疑**」是極強的訊號——
詐騙者主動教你規避第三方攔阻，等同於自證。這種話術跨類型通用，值得單獨當一條訊號。
