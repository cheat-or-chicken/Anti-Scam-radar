- 類型：假買家騙賣家 / 假物流認證
- 用途：**B 堆 — 重建成對話當測試集 ＋ 餵詐騙 agent（共用）**
- **這則是法院認定的犯罪事實，含精確時間戳，簡報上份量最重的一則**

## 法院認定之詐術（附表「詐欺時間及方式」欄原文）

> 本案詐欺集團成員於114年6月6日11時1分許，以社群軟體Dcard暱稱「Cyz」向張曉晴佯稱：
> 欲向其購買演唱會門票，但要透過順豐快遞寄送門票，須先簽署託運條款、完成金融認證，
> 又因未能及時完成交易，而帳戶遭列警示，需依指示操作解除等語，
> 致張曉晴陷於錯誤，而依指示匯款。

## 推進順序（法院版本，可直接拿來打骨架）

1. 欲向其購買演唱會門票 → 接觸 + 利益理由
2. 須透過順豐快遞寄送、簽署託運條款 → 製造程序正當性
3. 完成金融認證 → 引導進入金融操作
4. 未能及時完成交易，帳戶遭列警示 → 恐懼壓力 + 時間壓力
5. 需依指示操作解除 → 交出控制權

## 證據欄（說明為何取不到逐字稿）

> ②告訴人張曉晴提供之**對話紀錄截圖**、匯款證明（偵卷第51至59頁）

對話截圖在偵查卷宗內，不隨判決書公開。故本則仍需重建。

## 重建注意事項

- **推進順序與時間必須完全依照法院認定**，不可自行增減步驟
- 話術細節可參考 165 同類型案例（B1-2）補足，但要在標註中註明哪些是補的
- 重建時六個半小時的節奏要體現出來（不是十則訊息就結束）

## 重建後要標的危險動作

點擊連結 / 簽署所謂託運條款 / 完成所謂金融認證 / 匯款（第一次匯款 = 控制權喪失點）
