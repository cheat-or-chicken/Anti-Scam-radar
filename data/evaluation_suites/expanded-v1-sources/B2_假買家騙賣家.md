# B1-2 誤信假買家話術 網路商家荷包失血

- 來源：165 打詐儀錶板　類型：假買家騙賣家（愧疚+恐懼路線）
- 用途：**B 堆 — 重建成對話當測試集 ＋ 餵詐騙 agent（共用）**
- 角色接力：假買家 → 假客服（視訊指導）

## 原始敘事

我前陣子將家中有一些嬰孩營養品刊登到臉書的二手母嬰用品社團，想說還沒超過保存期限，透過網路賣給有需要的人。沒多久，一名網友私訊我，表明對商品有興趣，希望透過7-11賣貨便系統交易。

對方隨後傳給我一個看似賣貨便的連結，方便我點進去填寫資料。我依照對方指示操作後，對方突然告訴我，因為我操作失誤，造成她的帳戶被鎖住，要我趕緊聯繫那個網頁的客服解鎖。

我當時沒有想到這可能是陷阱，便直接點擊網頁上的客服連結，跳轉出LINE的線上客服專員帳號讓我加入。客服隨即跟我聯繫，透過視訊一步步教我操作，對方說我不必打開鏡頭、分享手機畫面即可。

當時我誤認為對方在協助排除賣貨便系統異常，也沒多防備就照著客服指示去開啟網路銀行的相關功能進行驗證、輸入認證碼、開通無卡提款等功能。

我完全沒有意識到，自己把網銀許多重要操作權限資料都毫無保留攤平在陌生人面前，宛如網路個資裸奔。在客服的電話指示下，我陸續完成多筆轉帳及無卡提款卻不自知…。

與客服通話結束後，我回頭查看網銀帳戶，赫然發現交易紀錄有多筆款項被轉出，存款數字縮水不少！

## 官方話術解析（165 原文）

1. 假意對網購商品有興趣，以購買商品為由接觸賣家，提供偽賣貨便網頁連結，引誘無辜賣家上鉤。
2. 假買家謊稱賣家操作失誤釀生買賣帳戶遭鎖定，進一步讓假客服登場，透過LINE假裝協助處理帳戶問題。
3. 假客服以驗證、解鎖為理由誘導視訊通話，要求分享手機畫面、輸入認證資訊及開通無卡提款。
4. 詐團取得操作機會後，完成多筆交易。

## 重建後要標的危險動作

點擊連結 / 分享手機畫面 / 輸入認證碼 / 開通無卡提款 / 轉帳

## 註記

「**分享手機畫面**」是這則獨有的危險動作，值得單獨列進清單——
它讓詐騙者取得即時視野，比要密碼更隱蔽。
