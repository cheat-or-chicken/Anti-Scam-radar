日常防護

主動偵測

頁面開啟、網址變更或新增敏感欄位時自動檢查。
發現風險時提醒，敏感操作前再次確認。

本機名單不是即時資料。未命中不代表安全；純數字網域不作相似性推斷。

進階分析

連接本機後端

將頁面標題、文字與欄位種類送往這台電腦的分析服務。
不傳送輸入值、密碼、Cookie 或網路請求內容。

允許 AI 輔助審查

透過後端將經初步遮罩的文字與程式片段送至 OpenAI，
分析可疑話術與程式碼合理性。可能產生 API 費用。

AI 審查不執行 JavaScript。遮罩不保證移除所有私密資訊，請勿在私密頁面啟用進階分析。

這不是 OpenAI API key。你的 API key 只保存在後端 config/config.local.json。

第一次連線

1. 在 Anti-Scam-radar 專案目錄啟動後端：

uv run python -m script.server

2. 開啟專案的 var/extension-token.txt，將內容貼到上方配對碼欄位。
3. 開啟「連接本機後端」，儲存後測試連線。AI 分析還需在後端設定 key 與上傳許可。

連線固定為 http://127.0.0.1:8765；不會將配對碼同步到其他裝置。
